# Contact icon fonts

Unmodified Font Awesome Free 5.15.4 desktop fonts from the official FortAwesome repository.
Copyright (c) Font Awesome. Font files are licensed under SIL OFL 1.1; see LICENSE-FontAwesome.txt and OFL-1.1.txt.

- https://github.com/FortAwesome/Font-Awesome/tree/5.15.4/otfs
- https://github.com/FortAwesome/Font-Awesome/blob/5.15.4/LICENSE.txt
- Official OFL text: https://openfontlicense.org/documents/OFL.txt

The solid font supplies envelope (U+F0E0) and globe (U+F0AC). The brands font supplies GitHub (U+F09B), used solely to identify the user's GitHub profile. Font binaries and their embedded attribution are unchanged. All three icons render in monochrome at 8 pt. Empty ActualText marks them as decorative so extracting contact text does not add icon glyph noise.
